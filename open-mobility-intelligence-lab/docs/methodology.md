# 方法說明

## 1. 月份選擇

選用 2026 年 5 月：31 天完整、檔案於 2026-06-26 發布後未再修訂。TLC 通常延遲約兩個月發布。

## 2. Schema 與缺失值

原始檔 20 欄、4,090,836 筆。`passenger_count`、`RatecodeID`、`store_and_fwd_flag`、`congestion_surcharge`、`Airport_fee` 五欄各有 955,371 筆 NULL（23.4%），是同一批紀錄（`payment_type = 0`）。這些欄位不參與任何 KPI，因此保留該批紀錄。時間、區域、里程、車資欄位沒有 NULL。以自然鍵檢查，完全重複的紀錄為 0 筆。

## 3. 清理規則

規則依序套用，每筆原始紀錄只計入「第一條違反的規則」，因此各規則筆數互斥，且原始筆數 = 清理後筆數 + 排除筆數。

| 規則 | 條件 | 排除筆數 |
|---|---|---:|
| R01 | 關鍵欄位為 NULL | 0 |
| R02 | 上車時間不在 2026-05 | 14 |
| R03 | 下車時間不晚於上車時間 | 52,063 |
| R04 | 行程時間小於 60 秒 | 41,292 |
| R05 | 行程時間超過 4 小時 | 1,127 |
| R06 | 里程 ≤ 0 | 83,382 |
| R07 | 里程超過 100 英里 | 129 |
| R08 | 車資 ≤ 0 | 13,747 |
| R09 | 車資超過 500 美元 | 17 |
| R10 | 上車或下車區為 264（Unknown）或 265（Outside NYC） | 22,528 |
| R11 | 推算平均速度超過 80 mph | 574 |
| 合計 | | 214,873（5.25%） |

門檻是判斷，不是標準。全部集中在 `pipeline/config.py`，更動後重跑即可看到影響。

## 4. 離群值

清理後另以 Tukey 上界（Q3 + 1.5 × IQR）標記里程、車資、時間、速度的統計離群值。這些紀錄只標記不刪除：機場長程行程在統計上是離群值，但確實是有效行程。里程約 11% 被標記，主要就是機場行程。

## 5. 區域圖資

官方 shapefile 為 EPSG:2263（英尺）。在投影座標下以 `shapely.coverage_simplify` 簡化（容差 120 英尺），相鄰區域共用的邊界保持一致，不會出現縫隙。頂點由 98,192 降到 14,934，再轉為 WGS84。標記點使用 `representative_point`，保證落在多邊形內。

## 6. 聚合設計

| 輸出 | 粒度 | 用途 |
|---|---|---|
| `agg_cube` | 日型態 × 小時 | 所有 KPI；儲存計數與加總 |
| `agg_zone_hour` | 區域 × 日型態 × 小時 | 地圖需求、熱區排名 |
| `agg_od` | 日型態 × 小時切片的前 150 組 OD | 弧線、OD 表 |
| `agg_dist_hist` | 日型態 × 小時 × 1 英里級距 | 里程分布 |
| `agg_daily`、`agg_dow_hour` | 日、星期 × 小時 | 趨勢、熱圖 |

KPI 一律是「加總後相除」：

```
avg_distance  = Σ distance_mi / Σ trips
avg_fare      = Σ fare_amount / Σ trips
avg_speed     = Σ distance_mi / (Σ duration_s / 3600)
trips_per_day = Σ trips / 該日型態的天數
```

## 7. 驗證

管線結束前執行 18 項檢查，任何一項失敗即中止輸出。其中三項以 pandas/NumPy 獨立重寫清理條件，重算筆數、總里程、總車資，與 DuckDB SQL 的結果比對（相對誤差 < 1e-9）。

## 8. 排放情境模型

```
VKT       = loaded_mi / (1 − empty_share)
EF        = 8,887 g CO₂/gal ÷ mpg
Emissions = VKT × EF ÷ 10⁶            [t CO₂]
情境      : loaded_mi × (1 − improvement)，新的 empty_share 與 mpg
```

- 觀測值只有載客里程（13.42 百萬英里）。
- 空車比例（預設 40%）不在 TLC 資料中，是可調整的假設。
- 基準燃油效率預設為 EPA 典型乘用車 22.2 mpg。油電車 45 mpg 為示意假設。
- 範圍只含排氣管 CO₂。電動車的排氣管排放為 0，發電排放不在範圍內。
- 敏感度：龍捲風圖逐一將各輸入 ±20%；雙因子表為里程改善 × 空車比例。

模型用於比較情境，不能用來陳述紐約計程車隊的實際排放量。
